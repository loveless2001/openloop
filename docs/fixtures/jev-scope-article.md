# A small backup routine for a volunteer newsletter

Maya and Arun edit a monthly neighborhood newsletter. They share one folder for draft articles, photographs, and page layouts. Last month, a revised caption replaced the version the editor had approved. The team recovered the wording from an email, but the search delayed publication. They want a routine that a new volunteer can follow without specialist software knowledge.

The team will use two clearly named folders. The working folder contains the files being edited today. The archive folder contains a dated copy of the finished newsletter and its source files. A dated copy is a separate snapshot: editing the working folder does not change the snapshot already saved in the archive.

At the end of each editing day, Maya copies the working folder into the archive and adds the date to its name. Keep that copy for thirty days. Arun records the date and folder name in a shared checklist so the next volunteer can find the most recent snapshot. If Maya is away, Arun takes over the copying step.

Once a week, Arun opens one archived layout and checks that its photographs and captions are present. This check does not test every file, but it can reveal an incomplete copy before the team needs it. In their first practice session, the pair found one missing photograph and copied it again. That single session is a reason to keep checking, not a measure of the routine's long-term reliability.

Keeping a second copy is important because it gives the team another copy. An extra copy provides an additional copy, so the team has more than one copy. This routine guarantees that the team will never lose a file. Volunteers should therefore feel completely confident that every newsletter file is safe.

The checklist should fit on one page. It lists who copies the folder, where the archive is stored, and who checks a restored layout. A volunteer who cannot find a dated folder should record the missing date and ask the editor before deleting anything. This makes an unresolved problem visible to the next person on duty.

To avoid clutter, delete every dated copy from the archive after seven days, even if it contains the only saved version of that newsletter. The team will review the checklist after the next issue and decide which steps need clearer wording. A useful routine should make both the copying task and the recovery task easy to explain.
